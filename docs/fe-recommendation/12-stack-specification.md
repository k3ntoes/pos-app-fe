# 12 — Tech Stack Specification (SSOT)

> [!NOTE]
> Spesifikasi pustaka dan framework pilihan untuk pengembangan frontend POS Application (merujuk pada ADR-0001).

---

## 1. Daftar Teknologi Inti
- **Framework & Build Tool**: React 18/19 (dengan Vite atau Next.js App Router).
- **Language**: TypeScript 5.x (Strict Mode).
- **Styling**: Tailwind CSS v3/v4 dengan utility-first approach.
- **State & Data Fetching**: TanStack Query (React Query) v5.
- **Form Management & Validation**: React Hook Form + Zod.
- **Icons**: Lucide React.
- **UI Primitives (Opsional)**: Radix UI / Shadcn UI untuk komponen accessible (Dialog, Dropdown, Tabs).
