# Antislop Skill

Use this skill whenever generating code, UI components, documentation, or responses to ensure they avoid generic AI "slop" patterns.

## Core Principles
1. **No Stereotypical AI-isms**: Avoid excessive comments explaining obvious code, robotic polite intros/outros, or overly generic placeholder text ("Lorem ipsum", "TODO: implement later").
2. **Specific & Context-Aware**: Write concrete implementation details suited precisely to the codebase architecture, domain rules, and requirements rather than generic textbook examples.
3. **Deep Module & Minimalist Code**: Follow YAGNI and minimalist principles. Do not add unnecessary wrapper functions, abstract factories, or bloated boilerplate.
4. **Clean UI & Content**: For frontend/UI tasks, avoid generic unstyled card grids with purple gradients, generic placeholder icons everywhere, or repetitive phrasing.
